### 1.5.2 Define Attributes ###

1. Click on Markables (The darker one)

   ![](res/1.5.2-1.png)

2. Click on the icon ![](res/1.5.2-2.png) to manage attributes. This displays the "Attributes Editor" window.

   ![](res/1.5.2-3.png)

 

3. Enter "Assertion" to the Attribute Type then ![](res/1.5.2-4.png) to save.

   ![](res/1.5.2-5.png)

4. Select assertion and type "conditional" as value then click ![](res/1.5.2-6.png) to save.

   ![](res/1.5.2-7.png)

5. Repeat steps 3 and 4 to add additional attributes type and values.

   ![](res/1.5.2-8.png)
