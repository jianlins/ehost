## 2.7 Save Annotations

* Quick Save  ![](res/2.7-1.png)
  * Quick Save for the annotations to the "saved" folder in the project folder. It will create a folder named saved automatically.

* Save As ![](res/2.7-2.png)
  * Export all the annotations to Knowtator XML files to a designated folder. Click change Path to change export file path.
     ![](res/2.7-3.png)

* Save prompts
  * eHOST asks whether to save when you close the application with unsaved changes.
  * eHOST also asks when you switch between annotation mode and adjudication mode with unsaved changes, because the two modes write to different folders. See [3.6 Adjudication Mode](3.6-Adjudication-Mode.md).
