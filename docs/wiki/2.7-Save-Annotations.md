## 2.7 Save Annotations

* Quick Save  ![](https://github.com/chrisleng/ehost/blob/master/res/2.7-1.png)
  * Quick Save for the annotations to the "saved" folder in the project folder. It will create a folder named saved automatically.

* Save As ![](https://github.com/chrisleng/ehost/blob/master/res/2.7-2.png)
  * Export all the annotations to Knowtator XML files to a designated folder. Click change Path to change export file path.
