## 3.3 Error Checking
When some errors happen, there will be a red wave under the annotations.

   ![](https://github.com/chrisleng/ehost/blob/master/res/3.3-1.PNG)

1. Select "pain control"

2. Click ![](https://github.com/chrisleng/ehost/blob/master/res/3.3-2.PNG) in the Editor Panel

   ![](https://github.com/chrisleng/ehost/blob/master/res/3.3-3.PNG)

3. Compare both annotations.

   ![](https://github.com/chrisleng/ehost/blob/master/res/3.3-4.PNG)

4. Click "Accept" or "Reject" to fix the error.
