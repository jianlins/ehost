## 3.3 Error Checking [^1]
When some errors happen, there will be a red wave under the annotations.

   ![](res/3.3-1.PNG)

1. Select "pain control"

2. Click ![](res/3.3-2.PNG) in the Editor Panel

   ![](res/3.3-3.PNG)

3. Compare both annotations.

   ![](res/3.3-4.PNG)

4. Click "Accept" or "Reject" to fix the error.

[^1]: Many of these instructions were based on https://github.com/chrisleng/ehost/wiki
