## 3.5 IAA Report
1. Click ![](https://github.com/chrisleng/ehost/blob/master/res/3.5-1.PNG) in Viewer.

   ![](https://github.com/chrisleng/ehost/blob/master/res/3.5-2.png)

2. Click "IAA Report" to generate IAA Reports

   ![](https://github.com/chrisleng/ehost/blob/master/res/3.5-7.PNG)

3. Select Annotations by Annotator and then click Next

   ![](https://github.com/chrisleng/ehost/blob/master/res/3.5-3.png)

4. Define what are matches or non-matches
 
   ![](https://github.com/chrisleng/ehost/blob/master/res/3.5-4.png)

5. Select Class

   ![](https://github.com/chrisleng/ehost/blob/master/res/3.5-5.png)

6. Click Generate Report to complete the processing

   ![](https://github.com/chrisleng/ehost/blob/master/res/3.5-6.png)
